# v2.8.1 internal refactor audit

Baseline: main c41a979a2013925d320269baf9663cdcabd112cb (v2.8.0).

## Scope and findings

Inventory/static checks cover all 46 original root ES modules, 1176-line style.css, index.html, manifest, 18 assets, distribution folder, tests and both workflows. Focused behavioral review covers app.js, core.js, simple-ledger.js, db.js, navigation.js, updates.js, sw.js, cash projections and packaging. Static review is not proof that every dormant feature is bug-free.

1. High: publish/ drifted from root (UI, navigation, core venues, style, icons). Packaging omitted swipe.js and release.json. Restore the generated distribution from the v2.8.0 root; share the filename list between prepare/check tools. The root is the behavior baseline; stale publish/ is not a second UI specification.
2. High: baseline Node suite has 7 failures out of 178. Historical assertions assumed central-only venues, removed all-type statistics, old update text, and prohibited every MutationObserver (including the unrelated update status observer). Update assertions to observed v2.8.0 behavior, without modifying application behavior. Preserve invalid-venue validation using a fictitious venue.
3. Medium: app.js embeds pure cash projection adapters alongside DOM/state logic. Extract unchanged implementations to cash-projections.js, freeze the baseline implementations as differential fixtures, compare empty/mixed/100-record data and filters without mutation.
4. Medium: three optional IndexedDB reads repeat identical transaction/request/error/fallback handling. Extract one helper without changing keys, transaction mode, schema, callbacks or fallback behavior.
5. Medium: distribution scripts duplicated a long manual file list. Replace with one shared manifest; verify all 69 packaged files including assets and release metadata.
6. Low: remove 11 unused app imports: isGraded, calendarHome, STAGES, combination, load, styleView, raceHistory, typeVenueMatrix, periodInsights, ledgerInsights, periodComparison. Their modules contain no removed required initialization side effects.
7. Retained: core.js <-> simple-ledger.js is a pre-existing circular dependency. All domain modules import successfully; breaking this cycle requires a broader domain boundary change and is deferred.
8. Retained: CSS contains many repeated selectors across progressive overrides/media queries (text scan: 207 repeated selector strings, 51 !important occurrences). These counts are candidates, not proof of redundancy. Keep root CSS byte-identical; do not change cascade order.
9. Retained: navigation registers both popstate/hashchange; no new event listeners or rendering behavior introduced. Potential redundant Back renders should be assessed separately from this compatibility-only release.
10. Retained: DB save's exception handler checks tx.readyState, which is not a standard IDBTransaction property. No new failure was demonstrated; changing transaction abort semantics would be a separate bug fix. Schema, writes, validation, conflict handling and growth serialization remain unchanged.
11. Retained: classic/dormant UI functions, legacy exports, old assets, old browser suites. Do not delete based only on textual non-reference; classic mode and old backups remain supported.
